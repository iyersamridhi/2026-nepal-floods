# SEO & search indexing

Site URL: **https://2026-nepal-floods.vercel.app**

## Already on the site

- Keyword-rich `<title>` + `<meta name="description">` on every page
- Canonical URLs, Open Graph, Twitter cards
- [`/robots.txt`](../robots.txt) and [`/sitemap.xml`](../sitemap.xml)
- Updates page refreshes via GitHub Action (~every 30 min) when MoFA posts change

## Submit to Google (you do this once)

1. Open [Google Search Console](https://search.google.com/search-console)
2. Add property → **URL prefix** → `https://2026-nepal-floods.vercel.app`
3. Verify with the HTML tag or DNS method Google shows
4. After verified: **Sitemaps** → submit `https://2026-nepal-floods.vercel.app/sitemap.xml`
5. Use **URL Inspection** on `/` and `/updates.html` → Request indexing

## Submit to Bing (optional)

1. Open [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Import from Google Search Console, **or** add the same site URL
3. Submit the same sitemap URL
